# 🧮 Calculator

A fully functional web-based calculator with a clean, user-friendly interface. Built with vanilla JavaScript, this calculator supports all basic arithmetic operations and features a modern design.

## ✨ Features

- **Basic Operations**: Addition, subtraction, multiplication, and division
- **Decimal Support**: Handle decimal numbers with precision
- **Clear Function**: Reset calculator to start new calculations
- **Backspace**: Delete last entered digit
- **History**: View recent calculations
- **Responsive Design**: Works on desktop and mobile devices
- **Real-time Display**: Shows input and results in real-time
- **Error Handling**: Prevents invalid operations

## 🛠️ Tech Stack

- **HTML5**: Calculator structure and buttons
- **CSS3**: Modern styling and responsive layout
- **Vanilla JavaScript**: Calculator logic and event handling

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/SomPNG/Calculator.git
cd Calculator
```

### 2. Open in Browser
```bash
# Open index.html directly

python -m http.server 8000

```

## 📖 Usage

1. **Number Input**: Click number buttons (0-9) to input numbers
2. **Operations**: Click +, -, ×, ÷ to select operations
3. **Decimal**: Click . to add decimal point
4. **Calculate**: Click = to see the result
5. **Clear**: Click C to clear all values
6. **Backspace**: Click ← to delete last digit

## 💡 Examples

- `5 + 3 =` → 8
- `10 × 2.5 =` → 25
- `100 ÷ 4 =` → 25
- `7.5 - 2.3 =` → 5.2

## 🎨 Features Details

### Display
- Shows current input and calculation results
- Updates in real-time as you type
- Clear formatting for easy reading

### Operations
- **Addition (+)**: Adds two numbers
- **Subtraction (-)**: Subtracts second number from first
- **Multiplication (×)**: Multiplies two numbers
- **Division (÷)**: Divides first number by second

### Special Functions
- **Clear (C)**: Resets the calculator completely
- **Backspace (←)**: Removes the last entered digit
- **Decimal (.)**: Allows decimal number input
